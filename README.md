# Titanic Survival Analysis

## Project Overview
An Exploratory Data Analysis project investigating passenger survival patterns from the Titanic disaster using Python.

## Business / Analytical Problem
The objective is to understand which passenger characteristics were associated with survival and explore patterns across different passenger groups.

## Objectives
- Explore Titanic passenger information.
- Identify and handle missing values.
- Analyze passenger demographics.
- Investigate survival patterns by gender and passenger class.
- Explore relationships between age, fare, and survival.
- Visualize important patterns using statistical charts.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The project uses Titanic passenger data containing:
- PassengerId
- Survived
- Pclass
- Name
- Sex
- Age
- SibSp
- Parch
- Ticket
- Fare
- Cabin
- Embarked

## Project Workflow
1. Data Loading
2. Data Inspection
3. Data Type Conversion
4. Missing Value Treatment
5. Univariate Analysis
6. Bivariate Analysis
7. Multivariate Analysis
8. Survival Analysis
9. Correlation Analysis
10. Data Visualization

## Key Questions
- Which gender had a higher survival rate?
- Did passenger class influence survival?
- How did age relate to survival?
- Were ticket fares associated with survival?
- Did survival patterns differ by embarkation port?

## Conclusion
This project demonstrates the use of Python for exploratory data analysis, data preprocessing, statistical visualization, and extracting insights from historical passenger data.
